== O que a leitura do código mudou no plano (antes de escrever) ==
- A F12 já era um gateway com nome trocado: `aplicarEventoDoGateway` recebe um evento genérico e
  `(gateway, event_ref)` é único. O adapter do Stripe TRADUZ; não há máquina de estados nova.
- `gateway_ref` na F12 recebia o id do EVENTO (semântica do mock). Para o Stripe a referência
  estável é a subscription (`sub_…`) — é por ela que o webhook seguinte acha a organização. O
  evento ganhou `subscription_ref` opcional; no mock nada mudou.
- O `.env.e2e` chega ao app sob teste pelo `webServer.env` do Playwright, e o `env:` do config vence
  o arquivo — é onde `STRIPE_API_BASE` aponta para o Stripe falso, porque só o config sabe a porta.

  aberta — reler por `lerAssinaturaEm(db, …)`.
